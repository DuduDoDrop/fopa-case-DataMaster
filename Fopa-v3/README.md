# Fopa-v3 — a documentação da solução

> [!abstract] Em uma frase
> Este é o vault Obsidian com a documentação completa do FOPA como está em produção (v3.1): 148 notas em 16 famílias, ligadas entre si, com fluxogramas, mapa mental, capturas de tela do site e a rastreabilidade de cada requisito do case.

## Papel na solução

É a documentação de referência: explica o problema, a arquitetura, cada fluxo nó a nó, cada página, os dados, as técnicas de IA, as medições, as decisões, a infraestrutura, a segurança, a base legal, a escalabilidade, a reprodução e a evolução — sempre apontando para os arquivos do repositório que sustentam cada afirmação.

## Como abrir

- **No Obsidian:** "Abrir pasta como cofre" e escolher esta pasta (`Fopa-v3`). A configuração do vault vem junto: cores por família no grafo, favoritos, modelos de nota e o canvas.
- **No GitHub ou em qualquer editor:** as notas são Markdown comum; os diagramas são Mermaid, que o GitHub desenha.
