# amostras/ — a licitação de teste versionada

`_fixture/` guarda uma licitação real e pública do PNCP — uma concorrência eletrônica de São Lourenço do Sul/RS, com edital retificado e termo de referência —, com os PDFs, o texto extraído, o inventário e os metadados. Os testes usam essa pasta para exercitar a leitura, o documento vigente depois de retificação e a verificação sem depender da rede.

As demais licitações do acervo não vão para o repositório: são reproduzíveis a partir do PNCP e ficam no armazenamento da solução.
